Drop probe

Drag one mail out of Outlook and drop it below. This reports the shape of what the browser received, so we can tell whether new Outlook hands a file over at all.

It never shows the content of anything. Only names, sizes, MIME types and character counts are printed — never the text of a mail, a field or an attachment. That is deliberate: the report is safe to read out or screenshot without leaking a real document. This file lives in _test/ and is gitignored; it is not part of either app.
